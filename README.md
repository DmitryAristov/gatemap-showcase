# GateMap

An Android app for drivers crossing the border.

- **Checkpoint congestion:** waiting times, queue lengths, processing rates and recent crossings.
- **Map:** checkpoint locations and facilities, with custom light and dark 3D map styles.
- **Your queue:** estimated vehicles ahead, waiting time and queue progress.
- **Camera alarm:** tracks the vehicle ahead and sounds an alert when it starts moving. Works day and night.

Languages: Russian, Kazakh and English.

[Google Play](https://play.google.com/store/apps/details?id=com.gatemap) · [Website](https://gatemap.dev)
